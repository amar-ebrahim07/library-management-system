# University Library Management System

A console-based Library Management System written in Python using object-oriented programming.

## Features

- Add books
- Remove books
- Edit books
- Register members
- Borrow books
- Return books
- View transactions
- Persistent storage using text files

## Technologies

- Python
- Object-Oriented Programming
- File Handling

## Project Structure

- main.py - User interface
- library.py - Business logic
- book.py - Book class
- member.py - Member class
- transaction.py - Transaction class

## How to Run

```bash
python main.py
```
